02 / CROSSINGS

교차로와 모델 진행 상황

교차로 개략도이며 GPS 지도가 아닙니다. 파란색 표시는 로봇이 마지막으로 보고한 교차로입니다. '이동 중'은 목적지를 뜻하며 도착을 의미하지 않습니다.

실시간 빨간불실시간 초록불모델 예측합의 부족유효한 데이터 없음

일치하는 교차로가 없습니다.

모델 confidence는 단일 프레임 시각 confidence와 다릅니다. 방문 통계는 종료된 방문을 집계한 것이며, 반복 방문은 매번 개별 집계되고 로봇 수는 중복 제거됩니다. 첫 시각은 시뮬레이션 시간이며, 상세에는 실제 기록 시각이 유지됩니다.

전체 교차로 개요

색상 블록을 클릭해 관측과 학습 결과를 확인하세요. 검색은 이 개요에도 함께 적용됩니다.
